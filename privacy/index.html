Esta información se refiere a la web laiaromerodesign.com. El funcionamiento de la app Criptika se describe por separado en su política de privacidad.

1. Responsable y contacto

Laia Romero Carol es la responsable de esta web. Puedes escribir a laiaromerodesign@gmail.com.

2. Lo que la web no utiliza

La web no usa cookies, herramientas de analítica, publicidad ni formularios. Las tipografías y las librerías necesarias para mostrar las páginas se sirven desde la propia web, no desde proveedores adicionales.

3. Alojamiento

La web está alojada en Vercel. Como cualquier servidor web, recibe las peticiones de tu navegador, que incluyen tu dirección IP, el navegador y el sistema operativo, y la página solicitada. Según su aviso de privacidad, Vercel recoge información sobre el tráfico de las webs que aloja, como la dirección IP y la ubicación aproximada que se deriva de ella. La base jurídica es el interés legítimo en publicar la web y mantenerla segura.

4. Preferencia de idioma

Si eliges ES o EN, tu navegador guarda esa preferencia en su almacenamiento local para mostrarte las páginas en ese idioma. No se envía a ningún servidor ni se utiliza para otra finalidad. Puedes borrarla eliminando los datos de este sitio en tu navegador.

5. Consultas por correo electrónico

Los enlaces de correo abren tu aplicación de correo. Si escribes, recibiré tu dirección y la información que decidas incluir, y la usaré para responder a tu consulta, no para enviarte publicidad.

La base jurídica es la aplicación de medidas precontractuales cuando la consulta trata sobre un posible encargo y, para otras consultas, el interés legítimo en responder las comunicaciones recibidas. Los mensajes se conservarán durante el tiempo necesario para gestionar la consulta y, cuando proceda, durante los plazos necesarios para cumplir obligaciones legales o atender reclamaciones.

El correo se gestiona mediante una cuenta gratuita de Gmail, un servicio de Google. Google tiene servidores en distintos países, por lo que los mensajes pueden tratarse fuera del Espacio Económico Europeo, incluido Estados Unidos. Para estas transferencias, Google indica que se basa en decisiones de adecuación, en el Marco de Privacidad de Datos UE-EE. UU., en el que Google LLC está certificada, y en cláusulas contractuales tipo cuando son necesarias. Puedes consultarlo en los marcos legales para la transferencia de datos de Google.

6. Enlaces externos

Los enlaces a otras webs, como LinkedIn, Apple, Vercel o Google, te llevan a servicios con sus propias políticas de privacidad. Esos servicios solo reciben datos si abres el enlace.

7. Tus derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación y portabilidad, cuando correspondan, escribiendo a laiaromerodesign@gmail.com. Si consideras que no se han respetado tus derechos, puedes presentar una reclamación ante la Agencia Española de Protección de Datos: https://www.aepd.es.
